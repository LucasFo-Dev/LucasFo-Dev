Projeto em equipe de uma proposta de onboarding. Minha contribuição foi a **modelagem de um banco Oracle com 12 entidades e o script DDL**, com chaves, relacionamentos e restrições de integridade.

### ☕ [Techpoint Sales — API REST](https://github.com/LucasFo-Dev/Techpoint_Sales)

Aplicação acadêmica em **Java e Spring Boot**, com **Oracle, JPA e Hibernate**, para clientes, produtos e vendas. Inclui relacionamentos entre entidades, validação de estoque e cálculo de totais.

### 📱 [CryptoPulse Compose — Android e APIs](https://github.com/LucasFo-Dev/CryptoPulse_Compose)

Aplicação acadêmica em **Kotlin e Jetpack Compose** para consulta de cotações por API REST, com Retrofit/Gson, Coroutines, ViewModel, StateFlow e tratamento dos estados de carregamento, sucesso e erro.
